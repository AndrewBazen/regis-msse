    How to play 403: The Game

    Each level is a small web app with a Broken Access Control flaw. Your job: exploit it to reach something you shouldn't — then read the postmortem to learn the fix.

    The App

    A fake web page shown in a browser frame. This is your target.

    The Inspector

    The live request — URL, method, cookies, decoded JWT, and body — all editable. The pane that matters this level is opened for you.

    The Goal Card

    Who you are and what to access this level, plus a hint if you get stuck.

    1. Read the level briefing (the concept) and the Goal Card (your target).
    2. Change one thing in the Inspector.
    3. Hit ▶ Send Request (or Ctrl+Enter).
    4. Wrong attempts explain why they failed — adjust and try again.
    5. On success, a Postmortem shows the vulnerable vs. secure code. Then advance.

    Reopen this anytime with ？ How to play (top bar), or a level's concept with 📖 Briefing.
